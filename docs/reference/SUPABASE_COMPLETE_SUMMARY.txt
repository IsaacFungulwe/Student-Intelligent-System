🚀 HOW TO GET STARTED (10 MINUTES)
═══════════════════════════════════════════════════════════════════

STEP 1: Read Documentation (2 minutes)
────────────────────────────────────────────────────────────────
   Open: START_HERE_SUPABASE.md
   Follow: SUPABASE_CREDENTIALS_SETUP.md

STEP 2: Create Supabase Account (3 minutes)
────────────────────────────────────────────────────────────────
   1. Go to: https://supabase.com
   2. Sign up with GitHub or email
   3. Create new project
   4. Wait for initialization (2-3 min)

STEP 3: Setup Database (2 minutes)
────────────────────────────────────────────────────────────────
   1. Open Supabase Dashboard → SQL Editor
   2. Copy content from: supabase_schema.sql
   3. Paste and click "Run"
   4. Verify tables in Table Editor

STEP 4: Get Credentials (1 minute)
────────────────────────────────────────────────────────────────
   1. Go to: Project Settings → API
   2. Copy: Project URL
   3. Copy: anon public key

STEP 5: Configure App (1 minute)
────────────────────────────────────────────────────────────────
   Edit: local.properties

   Add these lines:
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_ANON_KEY=your-anon-key-here

STEP 6: Build Project (1 minute)
────────────────────────────────────────────────────────────────
   In Android Studio:
   • File → Sync Project with Gradle Files
   • Build → Make Project

STEP 7: Test Connection
────────────────────────────────────────────────────────────────
   Add to any Activity:

   if (SupabaseConfig.isConfigured()) {
       Toast.makeText(this, "Supabase ready! ✅", Toast.LENGTH_SHORT).show();
   }
