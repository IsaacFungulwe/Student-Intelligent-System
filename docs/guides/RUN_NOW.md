# 🎯 QUICK START - Run in 4 Steps

## 1️⃣ SYNC GRADLE (First Time - Required!)
```
Android Studio > File > Sync Project with Gradle Files
⏱️ Wait 1-2 minutes for dependencies to download
✅ Look for "Gradle sync finished" in bottom status bar
```

## 2️⃣ BUILD PROJECT
```
Build > Clean Project
Build > Rebuild Project
✅ Wait for "BUILD SUCCESSFUL"
```

## 3️⃣ START EMULATOR/DEVICE
```
📱 Emulator: Tools > Device Manager > Click ▶️
📱 Device: Connect via USB + Enable USB Debugging
```

## 4️⃣ RUN APP
```
Click Green ▶️ Run Button (Top Right)
OR Press: Shift + F10
✅ App installs and launches automatically
```

---

## 📝 First Time Setup Flow

### In the App:
```
1. Register Admin (school details)
2. Login as Admin → Register Teacher
3. Login as Admin → Register Parent
4. Login as Teacher → Register Student
5. Login as Teacher → Add Results + Comments
6. Login as Parent → Click "AI Performance Analysis" 🤖
7. Select Student → Click "Analyze with AI"
8. Wait 5-10 seconds → View AI Report! ✨
```

## ⚠️ Common Issues

### "Cannot resolve BuildConfig"
```bash
File > Sync Project with Gradle Files
```

### "No internet" during AI analysis
```bash
Check emulator/device has internet connection
```

### "No academic data"
```bash
Login as Teacher first
Add results for student
Then try AI analysis
```
